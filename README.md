# StarDC Manager

Aplicație de management pentru obiective și proiecte StarDC.

## Features
- 🎯 Obiective (goals) — adaugă și bifează
- 💼 Proiecte — organizate pe foldere cu detalii complete
- 🔄 Sync live la 5 secunde
- 📱 Instalează ca app (PWA) pe Windows, Android, iOS

## Deploy pe Render

1. Creează **New Web Service** (nu Static Site!)
2. Conectează repo-ul
3. Setări:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Environment:** Node
4. Done! 🚀

## Instalare ca App
- **Windows/Chrome:** click pe iconița de instalare din bara de adrese
- **Android Chrome:** meniu → „Instalează aplicația"
- **iOS Safari:** Share → „Adaugă pe ecranul principal"
